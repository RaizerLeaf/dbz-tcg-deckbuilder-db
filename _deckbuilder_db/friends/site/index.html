DBZ TCG Deck Helper

PanZ era (Sets 1–7). No AI is built into this page: you bring your own free chat AI (Claude, Gemini, ChatGPT) and this page gives it the cards, then checks what it builds.

  1. Pick the Main Personality (MP) you want to build around, and the styles worth comparing. Fewer styles make a smaller file.
  2. Download or copy the pack. Start a new chat with your AI, upload the file (or paste it) and send the starter message below.
  3. The AI compares styles, then builds a list. Copy that list into 2. Check a deck to catch rule mistakes and get the deck code.
